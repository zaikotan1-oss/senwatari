# 線でわたれ！

線を一本描くと、それが物体になって落ちる。橋や坂を作って、車（やブタや機関車や UFO）を向こう岸の旗まで送る物理パズル（100 面。5 面ごとに絵柄がガラッと変わる 20 種）。

- あそぶ: https://zaikotan1-oss.github.io/senwatari/ （スマホ・iPad は「ホーム画面に追加」でオフラインでも遊べます）
- 1 ファイル版: `senwatari-single.html` をダウンロードしてブラウザで開く

物理エンジンは [Matter.js](https://github.com/liabru/matter-js)（MIT License）を同梱しています。
